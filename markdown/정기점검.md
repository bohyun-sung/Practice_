- `https://10.10.28.3`
- `1280118` / `hanwhaHLI6363!@#` (`Hlihli1234567&` 로 변경)
- 우측 상단아이콘 클릭 > 패스워드 계정 설정 메뉴 진입하여 비밀번호 변경

1. 로그인 > Password Safe > Accounts > Local Accounts > 조회 목록 중 접속하려는 서버의 계정 Access 선택
2. AD 계정에 대한 로그인 > Password Safe > Accounts 탭 선택 > Directory Linked Accounts 탭 선택 > 권한 부여 받아 조회되는 목록 중 접속 하려는 서버 계정 선택
3. Quick Launch > 세션 사용 기간 설정 > reason(optional) 작성 > Start SSH Session 클릭 > 대상 서버 접근 및 사용 가능
4. 해당 세션 exit를 통해 종료하였더라도 적용한 세션 유지 시간동안 대상 서버 바로 접근 가능

> Putty 종료되어 다시 세션 바로접근 방법: Requests 탭 선택 > 조회되는 서버 목록의 `vertical 3 dots` 아이콘 선택 > View Request Details 클릭 > Start Session 클릭
> `스텝 1`의 사용자가 접속한 동일한 서버의 동일한 계정으로 Access 요청할 경우 중복 로그인으로 서버 접근 불가.
> UTC 시간대의 +9 이후 시간대로 적용하여 대상 서버 접근 예약 신청 및 사용 가능
> `스텝 3`과 다르게 Quick Launch 탭이 보이지 않음 > Submit Request alert메시지의 UTC 시간 +9 이후 시간대로 시작시간 변경 후 Submit Request 요청
> 바로 접근하여 사용하고자 할 경우 이전 사용자가 연결되어있는 대상 서버의 세션 해제 요청이 필요
> 해제 방법: Password Safe > Requests > 접속 연결이 있는 서버의 우측 `vertical 3 dots` 선택 > View Request Details > Check-In Request
> 기존 세션 재연결 방법: 위 `해제 방법` 따라가서 마지막에 `Start Session`
> Approvals 는 서버에 접근하는 일반사용자가 세션접근 요청시 승인 권한이 있는 PWS 사용자가 허용/거부 진행 가능한 기능
